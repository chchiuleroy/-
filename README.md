# 🧧 尾牙抽獎系統 | Lucky Draw System

一款純前端、無需後端的年終尾牙抽獎網頁應用，透過上傳 Excel 名單即可立即開始抽獎，支援動畫、音效、語音播報與自動匯出 CSV。

## ✨ 功能特色

- **零安裝**：單一 HTML 檔案，用瀏覽器打開即可使用
- **Excel 驅動**：上傳 `.xlsx` 檔案自動讀取員工名單與獎項設定
- **滾輪動畫**：抽獎過程有隨機滾動姓名的動態效果
- **彩帶特效**：中獎瞬間觸發 canvas-confetti 彩帶慶祝動畫
- **語音播報**：Web Speech API 自動朗讀「恭喜中獎」
- **音效播放**：中獎時播放音效
- **防重複中獎**：已抽中者自動從名單移除
- **獎項管理**：可切換不同獎項，各自控管剩餘名額
- **自動存檔**：每次抽獎後自動下載 CSV 中獎紀錄
- **手動匯出**：可隨時手動匯出完整中獎名單（含時間戳）
- **RWD 響應式**：支援桌機與平板寬度

## 📁 專案結構

```
抽獎/
├── index.html        # 主程式（完整單頁應用）
└── 抽獎名單.xlsx     # 範例名單（Sheet1: 員工, Sheet2: 獎項）
```

## 📊 Excel 格式說明

### Sheet 1：員工名單

| 公司 | 姓名 |
|------|------|
| 某某公司 | 王X明 |
| 某某基金會 | 李X芬 |

### Sheet 2：獎項設定

| 獎項 | 獎品名稱 | 數量 |
|------|----------|------|
| 廠商獎3 | 現金500元 | 25 |
| 廠商獎4 | 大同電鍋 1台 | 5 |

> 欄位名稱需包含「公司」、「名」、「獎項」、「數量」等關鍵字，系統會自動辨識。

## 🚀 使用方法

1. 下載 `index.html`
2. 用任意瀏覽器（Chrome / Edge 建議）開啟
3. 準備符合格式的 Excel 檔案，點擊「選擇 Excel 檔案」上傳
4. 從下拉選單選擇欲抽的獎項
5. 點擊「開始抽獎」按鈕
6. 中獎結果自動顯示並下載 CSV

## 🛠 技術棧

| 技術 | 用途 |
|------|------|
| HTML / CSS / JavaScript | 純前端，無框架依賴 |
| [Tailwind CSS](https://tailwindcss.com/) (CDN) | 排版與樣式 |
| [SheetJS (xlsx)](https://sheetjs.com/) | 讀取 Excel 檔案 |
| [canvas-confetti](https://github.com/catdad/canvas-confetti) | 彩帶動畫特效 |
| Web Speech API | 語音播報（瀏覽器內建） |
| Google Fonts - Noto Sans TC | 中文字型 |

## ⚠️ 注意事項

- 需要網路連線載入 CDN 資源（Tailwind、SheetJS、confetti）

- 建議使用 Chrome 或 Edge 瀏覽器以獲得最佳 Web Speech API 支援
